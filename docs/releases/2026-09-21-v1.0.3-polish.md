# 1.0.3 polish and validation — 21 September 2026

Working version is now **1.0.3**. This pass extends the pre-existing campaign/presentation work in the checkout. Changes are local and uncommitted; no export, tag, push or publication was performed.

## Fixes

- **Tuesday crash:** the live debugger identified `MatchUI._on_campaign_deal_requested` assigning an untyped empty Array to `Array[String]` on day two and later. The empty list now has an explicit typed initialization. The campaign regression now starts and completes Tuesday Morning, rather than stopping at its briefing.
- **Collector audio:** the original arrival stopped before the prominent engine burst (~1.3 seconds into the supplied clip). Playback now begins at 1.25 seconds, with an audible attack and a sequential fade before stopping. Interruption restores the portrait and stops audio. Teardown releases the stream.
- **Shop/dialogue:** selecting an already-selected drink no longer re-emits inspection; identical visible NPC speech keeps its reveal position. Invalid IDs are ignored. Locked and completed actions retain the correct disabled labels. Typewriter timing uses parsed character count.
- **Handbook:** underlying cup gestures, wallet shortcuts and game hotkeys are blocked while the handbook is open. The reference preserves the current deal.
- **Money HUD:** restored current-deal income beside the wallet. Both numeric amounts and the event-table balance have separate literal `VNĐ` units. HUD numbers start at 30 px versus 14 px units and shrink only as necessary to fit large balances. Income stays linked to `current_deal_earnings_points`; wallet animations retain their existing accounting authority.
- **Major events:** Ù, Ù khan and Exhaustion play the existing jackpot cue when their ceremony starts. Normal completion or cancellation stops that cue; presentation does not issue a second payout.
- **SET extension:** ordinary SET extensions remain delta-only, including when old cards carry Liquid/MELD_RETRIGGER. Full-meld native and Liquid passes are permitted when the resulting SET reaches exactly 4, 8, 12, ... cards. RUN behavior, qualifying Gold, polish contributions, new melds and Exhaustion retain their existing rules. Preview, scoring, receipts and handbook share the rule.

## Service pricing implemented

“Player-based” is interpreted as **current wallet balance**, with daily repeat counts. Existing percentage rates and minimums are retained; repeat multipliers are **1×, 2×, 3×, ...**, separately for each category.

| Service | Base before repeat multiplier |
| --- | --- |
| Polish two cards | max(10,000 VNĐ, 2% of current wallet rounded up to 500 VNĐ) |
| Tip | max(5,000 VNĐ, 1% of current wallet rounded up to 500 VNĐ) |
| Lottery ticket | max(10,000 VNĐ, 1% of current wallet rounded up to 500 VNĐ) |

Counts commit before wallet notifications and survive reopening/save-resume. New days reset counts. Old saves recover missing polish/tip counts from the current-day wallet journal. Lottery counts come from purchased tickets. Buy All simulates each successive deduction and multiplier, so its quoted quantity/total matches purchase execution. Purchased ticket stakes are immutable and determine payouts. Drink, relic and Gieo pricing remains on its existing basis.

## Menu, handbook and difficulty follow-up

The rotating Pexel Grotesk title is drawn over the actual table. Continue animates its letters into the header while menu controls fade in; the same four words receive live music-band pulses. The opening transition accepts pointer, keyboard, touch and controller input, and the title remains available when returning to the menu.

There is one visible handbook entry. Relics use catalog sprites both in the list and in their detail view. Fresh settings and translation fallback default to English; an existing saved language choice is preserved. Starting or resuming from the run menu requires an explicit Playlist / Authored DJ Sets choice; Options can change it afterward.

Difficulty 1 retains the original debts. Each subsequent difficulty doubles all seven daily requirements (Difficulty 2: Monday 500,000 VNĐ, Sunday 32,000,000 VNĐ). Paying Sunday unlocks the next level before offering Endless or Exit to Menu. Endless retains the current run and grows its debt by 50% daily. Exiting no longer silently begins a new run. Unlocks live separately in `user://difficulty_progress.cfg`; replacing a run does not erase them. Run snapshots include difficulty; legacy snapshots default to Difficulty 1. The supported selector range is 1–28, keeping weekly targets below the existing Endless saturation boundary.
