# TRADATALA 1.0.2 release checkpoint — 2026-09-19

## Scope

Total checkpoint of the current tracked and untracked project state, including gameplay, campaign, saves, services, relic shop, event-table journey, card symbols, resolution/accounting presentation, translations, assets, tests, documentation, and the updated Godot AI editor addon. Existing deletions are included. Generated imports under `.godot`, personal test data, and build outputs remain ignored.

Gameplay is preserved as supplied. Release preparation changes version metadata to 1.0.2, adds `Web Full Release`, includes authored OST JSON in both full exports, excludes development directories, and adds `tools/build_full_release.ps1`. The restricted `Web Demo` preset remains available. The addon strips its editor helper autoload from both exported packs.

The broad runtime smoke was reconciled with the actual interface: New Game opens the run menu; Drink tiles inspect and explicit Order purchases; Starter Event supports multiple NPCs; shoe shine opens its implemented service; campaign outcomes use the accounting receipt. No production gameplay change was needed for these stale assertions.

## Implemented now

- Seeded seven-day campaign, four Deals and four Events per day, escalating debts, Sunday completion and Endless continuation.
- Committed-state autosave/continue and previous-file backup recovery.
- Drink prices, day gates and unlock progression; fortune-teller permanent deck transformations; lottery and shoe-shine services; seeded relic offers, paid rerolls, one purchase per visit, and equipment.
- Event journey overview, card-symbol art, trigger/scoring presentation, collection and outcome accounting, MVP/run scroll, Vietnamese and English.
- Reactive authored Cat/Dog music routes and the full 26-track jukebox.

Zodiac bosses/daily Zodiac modifiers, multiplayer, AI opponents, story chains and 3D remain unimplemented. These are not advertised as available in the prepared release description.
